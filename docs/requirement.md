# ゲーマー向けプロフカード共有サービス - 要件定義書

## 1. プロダクト概要

### 1.1 サービス名
（未定）

### 1.2 コンセプト
ゲームプレイヤー・ゲームストリーマーリスナー向けのプロフカード共有Webサービス

### 1.3 ターゲットユーザー
- メイン：ゲームプレイヤー、ゲームストリーマーリスナー
- 年齢層：10代後半〜20代
- SNS利用頻度が高いユーザー

### 1.4 解決する課題
- プロフカードを共有するプラットフォームの不足
- ゲーマー・リスナー特化のコミュニティがない
- 同じ趣味を持つ人との繋がりづくり

---

## 2. 機能要件（MVP）

### 2.1 認証機能
- Google認証によるログイン/ログアウト
- 未ログインユーザーはタイムライン閲覧のみ可能
- ログインユーザーはプロフカード作成・編集が可能

### 2.2 プロフカード機能
- 1ユーザーにつき1枚のプロフカードを作成可能
- 作成後の編集・削除が可能

#### プロフカード項目
| 項目 | 必須 | 形式 | 備考 |
|------|------|------|------|
| ニックネーム | ○ | テキスト | 最大20文字 |
| ひとこと | - | テキスト | 最大30文字 |
| 好きなゲーム | - | 複数選択 | マスターデータから選択 |
| 好きな配信者 | - | テキスト入力 | 複数人入力可能（最大5人） |
| プレイスタイル | - | 複数選択 | ガチ/エンジョイ/ひとりで/みんなと |
| プレイ時間帯 | - | 複数選択 | 朝/昼/夜/深夜 |
| SNSリンク | - | URL入力 | X/YouTube/Twitch/Discord |

### 2.3 タイムライン機能
- 新着順でプロフカードを一覧表示
- 無限スクロールで追加読み込み
- 1回の読み込みで20件表示

## 4. 画面設計

### 4.1 URL設計
| パス | 画面名 | 認証 | 説明 |
|------|--------|------|------|
| `/` | トップ（タイムライン） | 不要 | プロフカード一覧を表示 |
| `/login` | ログイン | 不要 | Google認証画面 |
| `/cards/new` | カード作成 | 必要 | プロフカード作成フォーム |
| `/cards/edit` | カード編集 | 必要 | プロフカード編集フォーム |
| `/cards/[id]` | カード詳細 | 不要 | 個別プロフカード表示 |

### 4.2 画面遷移
```
トップ（タイムライン）
  ├─→ ログイン → カード作成/編集
  └─→ カード詳細
```

## 5. データベース設計

### 5.1 テーブル構成

#### users（ユーザー）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | PK, Supabase Auth連携 |
| email | text | メールアドレス |
| created_at | timestamp | 作成日時 |

#### profiles（プロフカード）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | PK |
| user_id | uuid | FK → users.id |
| nickname | text | ニックネーム |
| bio | text | ひとこと |
| play_styles | text[] | プレイスタイル |
| play_times | text[] | プレイ時間帯 |
| favorite_streamers | text[] | 好きな配信者 |
| sns_links | jsonb | SNSリンク |
| created_at | timestamp | 作成日時 |
| updated_at | timestamp | 更新日時 |

#### profile_games（プロフカード×ゲーム中間テーブル）
| カラム | 型 | 説明 |
|--------|-----|------|
| profile_id | uuid | FK → profiles.id |
| game_id | uuid | FK → games.id |

#### games（ゲームマスター）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | PK |
| name | text | ゲーム名 |
| category | text | カテゴリ |
